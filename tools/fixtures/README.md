# Dados mínimos para os testes

Trechos de respostas públicas da ESPN, coletados em 17/11/2026. Foram mantidos somente identificadores, datas, equipes, placares, estado da partida e eventos de gols usados pelos testes. Não incluem contas, dados de usuários, publicidade, apostas ou artigos.

- `soccer-goals.json`: eventos 401916335, 401861194 e 401861189, via scoreboard de futebol.
- `soccer-summary.json`: resumo do evento 401861189.
- `nhl-scoreboard.json` e `nhl-summary.json`: evento 401891809 de 14/11/2026.

Esses arquivos são exemplos congelados para testes, não resultados atuais. A ESPN e os respectivos titulares mantêm os direitos sobre seus dados e marcas. Os testes também criam casos sintéticos de prorrogação, shootout e respostas inconsistentes para conferir o tratamento das exceções.
